## How this agreement is signed

There is nothing to print, sign or post. Assent is recorded by comment on your pull request.

When you open your first pull request, a bot comments asking you to agree to this document.
You reply on the pull request with exactly this sentence, on its own:

```
I have read the CLA Document and I hereby sign the CLA
```

The CLA status check then passes and your pull request can be reviewed. If the check does
not update, comment `recheck` to run it again.

**What is recorded.** Your GitHub username, your GitHub user id, the pull request number and
the time of your comment are written to `signatures/version1/cla.json` on the
`cla-signatures` branch of this repository. That file is public, as is this repository. No
postal address, legal name or email address is collected by this process.

The mechanism is
[contributor-assistant/github-action](https://github.com/contributor-assistant/github-action).
